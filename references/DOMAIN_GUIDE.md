# 教师工作量与排班负荷审计领域指南

## 业务问题

教师负荷只看课时数，忽略备课、作业反馈、家校沟通、跨校区通勤和连续授课，容易出现疲劳和质量波动。

## 产品解决方案

汇总教学与非教学任务，检查负荷分布、连续工作、通勤和高峰冲突，提出可执行调整。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `teachers` | 教师清单 | 是 | 编号和岗位，不填真实姓名 |
| `schedule_entries` | 课表与任务 | 是 | 授课、备课、反馈、沟通、行政和通勤 |
| `task_time_standards` | 任务工时标准 | 是 | 每类任务的标准工时 |
| `commute_data` | 跨校区与通勤 | 否 | 校区切换和路程时间 |
| `rest_rules` | 恢复窗口与限制 | 是 | 连续授课、休息和排班规则 |
| `role_scope` | 岗位范围 | 是 | 教师、教研或管理兼任 |
| `audit_period` | 审计周期 | 是 | 周、月或排班周期 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

非教学任务时长需采样；不能凭模型推断健康；个人限制需自愿、最小化并提供人工复审。
